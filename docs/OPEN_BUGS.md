- **P0 FG-RESUME:** при переключении на другое приложение FGallery возвращается к общему списку папок; сохранять папку, текущий просмотр и позицию.
- **P1 FG-PERM:** «Настроить доступ к фото/видео» не открывает действие; «Доступ ко всем файлам» корректно ведёт в системные настройки.
- **P1 FG-MOVE-SORT:** добавить выбор сортировки в пикере папки назначения.
- **P1 FG-VIDEO-SWIPE:** яркость и громкость должны проходить полный диапазон за один вертикальный свайп; остальной видеоплеер не менять.
- **ПРИНЯТО, НЕ ПЕРЕДЕЛЫВАТЬ:** установка, перенос одного/нескольких, отмена, коллизия `_2`, CR2/3FR/IIQ, зум, Cleanup, обычное видео, панели, проверка обновлений.
