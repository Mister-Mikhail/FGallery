## Цель
Разработать быструю офлайн-галерею Android (Kotlin/Compose, MediaStore/SAF, Room, LibRaw) и передать проверенный APK для **Samsung Galaxy S23, Android 16**. Сохранять файлы пользователя и уже подтверждённые функции. Не выдавать CI за физическую приёмку.

## Единый рабочий процесс
1. Перед задачей сверять текущий HEAD, перечисленные документы, открытые PR и GitHub Actions. Не считать старые отчёты доказательством.
2. **Единственная активная ветка:** `feature/fgallery-0.4.0-integration`; draft PR #15. PR #11–#14 — исторические этапы, не продолжать в них разработку. Не сливать в main без прямого разрешения.
3. Вносить только изменения по критериям приёмки; без отвлекающих редких кейсов, рефакторинга и повторных одинаковых коммитов. Перед push проверять затронутые тесты; CI Android 16 и R8 — на интеграционной ветке.
4. Документы статуса и багов поддерживать короткими (не более 10–15 КБ каждый), обновлять **один раз по завершении пункта**, историю хранить в `docs/history/`. Не добавлять в каждый коммит отчёт.
5. Сборка для пользователя: `0.4.0` с новым `versionCode`, R8/JVM и Android 16 instrumentation должны пройти на точном SHA. QA — **GitHub prerelease**, не stable, с прямой ссылкой на ARM64 APK, SHA-256, номером сборки и кратким чек-листом. При ошибке исправить и повторить; не объявлять APK готовым по незавершённому CI.
6. Сообщать пользователю только о требуемом действии/решении, непреодолимом блокере или готовом проверенном APK. При невозможности автоматического продолжения честно сообщать ограничение, не обещать работу в фоне без действующего механизма.
7. Тестирование на S23 — отдельная пользовательская приёмка. До неё статус функций «в коде» или «CI пройден», но не «принято».

## Текущий приоритет (2026-11-02)
**Сначала выдать промежуточную QA-сборку текущего кода** для проверки пользователем, до новых изменений Stage 5. Тестировать: перенос/отмена, конфликт имён, мастер доступов, сеточные превью, RAW CR2/3FR/IIQ, зум, уборка, видео и обновление из приложения.

После базовой проверки: Room-каталог обновляется после move/rename/delete/restore; пошаговый USB/SAF scan; full-vs-incremental сравнение; настройки кэша Stage 3; проверить CR3 через LibRaw и embedded JPEG fallback. В видеоплеере **разрешено изменить только** тап по центральному полю для паузы/воспроизведения, тап по краям для панелей и задержку 250 мс в уборке. Остальные ранее принятые жесты, зум, Cleanup, RAW размеры, OPEN RAW и видео UI не менять.

## Безопасность
- Операции с файлами — без потери оригиналов: успех только после фактического результата, откат/отказ/отмена без падений, явное подтверждение опасной перезаписи или удаления.
- Секреты и подпись — только GitHub Secrets; не добавлять ключи в код.
- `СОГЛАСОВАНО` в ТЗ обязательно; `РЕШЕНИЕ НЕ ПРИНЯТО` не реализовывать.
- Отдельно проверять CR2, CR3, 3FR, IIQ; CR3 — ISO BMFF, не TIFF. Не удалять LibRaw fallback.
