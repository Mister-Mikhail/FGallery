## Stage6 — дубликаты
- **Точные копии:** совпадение размера, edge SHA-256 и полного SHA-256; ограниченная фоновая обработка, MediaStore/seekable SAF, проверка версии файла и CAS-запись в Room; автоматического удаления нет.
- **Визуальные кандидаты:** dHash и консервативный 48×48 RGB-screen для resize/crop, без тяжёлой RAW-проявки. Это только предварительная фильтрация, **не доказательство дубликата**.
- **Открыто:** полноразмерная проверка совпадающего участка с допуском только на масштаб/JPEG, исключение цветокоррекции, ретуши и разных кадров серии, подбор порогов на образцах пользователя, UI поиска/выбора папок, объяснение приоритета оригинала, подтверждение переноса в корзину. RAW+JPEG одной съёмки — пара, не дубликат; никакого автоматического удаления.
- Фоновая индексация не должна тормозить прокрутку и просмотр RAW.
