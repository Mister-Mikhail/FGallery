## Stage5 — каталог и сканирование
- Room-каталог, снимок для мгновенного старта, MediaStore generation/version delta, сверка живых ID, сохранение checkpoint при ошибке/отмене и прямое обновление после ряда собственных операций реализованы; подтверждённые build35 функции не изменять.
- **Открыто:** полноценная пошаговая USB/SAF delta и full-vs-incremental сверка; инвалидация/восстановление папок после всех мутаций, сохранение метаданных при переносах URI; проверка 2500 файлов и переподключений USB/SD (физический тест отложен пользователем).
- Полный страховочный проход остаётся; никогда не считать сбой чтения пустым каталогом.

## Stage6 — дубликаты
- **Точные копии:** совпадение размера, edge SHA-256 и полного SHA-256; ограниченная фоновая обработка, MediaStore/seekable SAF, проверка версии файла и CAS-запись в Room; автоматического удаления нет.
- **Визуальные кандидаты:** dHash и консервативный 48×48 RGB-screen для resize/crop, без тяжёлой RAW-проявки. Это только предварительная фильтрация, **не доказательство дубликата**.
- **Открыто:** полноразмерная проверка совпадающего участка с допуском только на масштаб/JPEG, исключение цветокоррекции, ретуши и разных кадров серии, подбор порогов на образцах пользователя, UI поиска/выбора папок, объяснение приоритета оригинала, подтверждение переноса в корзину. RAW+JPEG одной съёмки — пара, не дубликат; никакого автоматического удаления.
- Фоновая индексация не должна тормозить прокрутку и просмотр RAW.

## Правила завершения
JVM + Android16 instrumentation + R8 обязательны; публикация только QA prerelease с увеличенным versionCode, прямой ссылкой, SHA-256 и точным SHA коммита после зелёного CI. Не выдавать CI за проверку на S23. Документы обновлять после законченного пункта, историю хранить отдельно, не вести параллельных веток.
